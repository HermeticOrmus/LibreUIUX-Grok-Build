# Design Principles

Apply measurable, timeless principles (hierarchy, contrast, alignment, proximity, repetition, whitespace).

## Steps
1. Name the user job and primary action.
2. Check hierarchy: one dominant focal point.
3. Spacing: consistent scale; no accidental 13px gaps.
4. Type: limited scale; readable line length.
5. Color: accessible contrast; semantic meaning.
6. Summarize 3 concrete fixes.
