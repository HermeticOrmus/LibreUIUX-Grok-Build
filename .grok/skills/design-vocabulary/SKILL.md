# Design Vocabulary

Use precise terms: density, affordance, focal point, rhythm, elevation, state (default/hover/focus/disabled/loading), tap target.

## Teach cue
When the user is vague ("make it nicer"), translate into vocabulary + one principle, then ask for confirmation.
