# Design Vocabulary

Stub, not a playbook. No LibreUIUX-Claude-Code plugin carries a vocabulary skill one to one: the pack teaches these terms in its learning path [`beginner/design-vocabulary.md`](https://github.com/HermeticOrmus/LibreUIUX-Claude-Code/blob/main/beginner/design-vocabulary.md), which no marketplace installs. The nearest installable depth is the [`design-mastery`](https://github.com/HermeticOrmus/LibreUIUX-Claude-Code/tree/main/plugins/design-mastery) plugin: `grok plugin install design-mastery@libreuiux-grok --trust`.

Use precise terms: density, affordance, focal point, rhythm, elevation, state (default/hover/focus/disabled/loading), tap target.

## Teach cue
When the user is vague ("make it nicer"), translate into vocabulary + one principle, then ask for confirmation.
