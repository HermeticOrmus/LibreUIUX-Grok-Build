# Accessibility Audit

Stub, not a playbook. Real depth: the [`accessibility-compliance`](https://github.com/HermeticOrmus/LibreUIUX-Claude-Code/tree/main/plugins/accessibility-compliance) plugin from LibreUIUX-Claude-Code. Install it from this marketplace: `grok plugin install accessibility-compliance@libreuiux-grok --trust`.

Cover semantics, keyboard order, focus visibility, contrast, labels, errors, and motion preferences. Prefer WCAG 2.2 AA.
