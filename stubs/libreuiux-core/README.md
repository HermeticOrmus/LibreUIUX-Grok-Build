# libreuiux-core (Grok plugin stub)

v0 record, superseded in v1.0.0. This folder had no manifest, so `grok plugin install` took it as an unversioned plugin holding only a copy of the stub orchestrator. The melted skills now ship as [plugins/libreuiux-grok](../../plugins/libreuiux-grok/). The text below describes the v0 layout.

Bundles core LibreUIUX skills for install-from-path.

Skills live under repo `skills/` (canonical) and `.grok/skills/` (dogfood copy). Copy or symlink into this plugin's `skills/` when packaging. First-run install does not require this plugin; see [QUICK_START.md](../../QUICK_START.md).
