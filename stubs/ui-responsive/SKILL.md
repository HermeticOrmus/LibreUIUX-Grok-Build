# UI Responsive

Stub, not a playbook. No LibreUIUX-Claude-Code plugin carries a responsive review. The pack's command, [`.claude/commands/ui-responsive.md`](https://github.com/HermeticOrmus/LibreUIUX-Claude-Code/blob/main/.claude/commands/ui-responsive.md), lives outside any plugin, so no marketplace installs it; read it there until it moves into a plugin.

Check major breakpoints, stacking order, touch targets (≥44px), overflow, and content priority on small screens.
